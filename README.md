# Titanic Survival Prediction — Data Mining Project

## Project Description
In this project, we work on the Titanic dataset to predict whether a passenger survived or not. We treat this as a classification problem, and we also use clustering to group passengers who share similar characteristics (for example, age, ticket class, and fare). We use Decision Trees for the classification part and K-Means for the clustering part, and we compare the results of both.

## Project Motivation
We chose the Titanic dataset because it is a real historical event with clear and easy-to-understand data. It has different types of attributes (personal, social, and financial) that can affect whether a passenger survived, which makes it a good dataset to practice both classification and clustering on. It is also a clean and commonly used dataset, so we can focus more on applying the techniques instead of spending too much time cleaning the data.
